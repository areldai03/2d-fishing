# 研究中、釣り中。

大学院生が計算待ちの時間に大学裏の川へ出かける、縦画面のレトロ釣りRPGです。2000年代の携帯ゲームらしい手触りを、現代のブラウザとタッチ操作向けに再構成したオリジナル作品です。

## 起動方法

Node.js 20 以上を使用してください。

```bash
npm install
npm run dev
```

表示された URL（通常は `http://localhost:4173`）をブラウザで開きます。

```bash
npm test       # ゲームルールのテスト
npm run build  # 型検査と本番ビルド
npm run preview
```

## 操作

- マウス／タッチ：画面のボタンを押す
- Space：決定、キャスト、合わせ
- ファイト：アクションボタンまたは Space を押している間は「巻く」、離している間は「糸を緩める」
- 魚が走る予兆が出たらボタンを離し、テンションが落ち着いたら再び巻く

## 実装済み

- 研究机、大学裏の川、釣り人、水中のミカヅキを一枚に描いたピクセルアートのタイトル画面と日本語オープニングイベント
- ピクセルアートの研究室ホームと章内目標表示
- 研究室内の水槽、窓、ホワイトボード、PC、釣具箱を調べられるドット吹き出し
- 大学裏の川、青葉渓流（昼）のレイヤー背景と水面アニメーション
- 図鑑用の観測資料室、釣具屋店内、大学から渓流へ続く専用ルートマップ
- キャスト、前アタリ／本アタリ、魚種別ファイトの3フェーズ
- ファイト後は上下する取り込みゲージで最後の引き上げ。失敗すると魚に逃げられる
- 同じ魚種でも個体サイズで難易度が変化。大型ほど体力・引き・逃走が強く、取り込み範囲も狭い
- 魚種ごとの体型・ヒレ・模様を描き分けた専用ピクセルアート12種：オイカワ、ギンブナ、ウグイ、ドジョウ、コイ、ブラックバス、ナマズ、ヤマメ、アユ、カジカ、ニジマス、イワナ
- レア度・好物／許容エサ・岸際／流心／深場の生息傾向を分離した出現抽選。遠投は大型個体にも少し有利
- 魚ごとのサイズ帯、巨大判定、行動、生息域、好むエサ、価格
- 初観測／自己記録／巨大魚の捕獲演出
- 図鑑、最大記録、捕獲数、初観測地、サイズランク実績、好物、狙い目、難易度
- 観測メモ：章の出来事、初観測日、釣り場、自己最大、総捕獲数を整理した釣行履歴
- 釣果の売却、3系統×3段階の装備、購入・装着・物語ロック
- 序章から第一章への進行と青葉渓流の解放
- 渓流初訪問、ヤマメ観測、古い観測帳の発見までを描く第一章シナリオ
- キャラクター立ち絵、名前枠、会話ログを備えたノベルゲーム型イベント画面
- 解放済みシナリオを小さなキャラクター画像付きチャット形式で読み返し、場面ごと再生できる回想ログ
- 研究室の灯り、川面の反射、渓流の落ち葉と滝飛沫の背景アニメーション
- 研究室、大学裏の川、青葉渓流、資料室、釣具屋、移動画面ごとの環境音入りレトロBGM
- localStorage の自動セーブ、初期化画面
- PCキーボード、マウス、スマートフォンのタッチ操作

青葉渓流は大学裏で合計3匹かつ2魚種を観測すると解放されます。第一章はヤマメを含む渓流魚2種・合計3匹を観測し、ホームで報告すると完了します。完了報酬は「波読みの浮き」です。上位装備は第一章到達後に店へ並びます。少ない反復で新しい場所と物語へ進める調整です。

## 設計

- `src/data/`：魚、装備、ステージの追加可能なデータ定義
- `src/core/`：描画から独立した捕獲、記録、売却、購入ルール
- `src/core/fight.ts`：魚種別の体力・暴れ周期・テンション・距離を扱うファイトシミュレーション
- `src/game/`：Phaser の背景、水面、浮き、波紋、水しぶき描画
- `src/main.ts`：画面遷移と釣りアクションの状態管理
- `public/assets/fish/`：拡大表示可能な魚種別SVG
- `public/assets/fish-pixel-v2/`：単なる低解像度化ではなく、ピクセルクラスタから描いた魚種別PNG
- `public/assets/backgrounds/`：釣り場、研究室、資料室、釣具屋、ルートマップの専用背景
- `public/assets/characters/`：ノベルイベント用の主人公、森野先輩、鵜沢店主の立ち絵
