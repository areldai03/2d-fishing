# 研究中、釣り中。

大学院生が計算待ちの時間に大学裏の川へ出かける、縦画面のレトロ釣りRPGです。
キャスト、アタリ、魚とのファイト、最後の取り込みまでを、マウス・タッチ・キーボードで遊べます。

## 起動方法

Node.js 20 以上を使用してください。

```bash
npm install
npm run dev
```

表示された URL（通常は `http://localhost:4173`）をブラウザで開きます。

## 操作

- マウス／タッチ：画面のボタンを押す
- Space：決定、キャスト、合わせ
- ファイト：押している間は「巻く」、離している間は「糸を緩める」
- 取り込み：上下する印が金色の範囲に重なった瞬間にクリック／タップ

魚が走る予兆が出たら糸を緩め、テンションが落ち着いたら再び巻くのが基本です。エサ、投げる距離、装備によって狙いやすい魚や釣りやすさが変化します。
